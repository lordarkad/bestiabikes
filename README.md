# bestiabikes.com.ar

Sitio web estático de Bestia Bikes ("Velocidad · Marca"), una sola página `index.html` con estilos y scripts embebidos.

## Estructura

| Ruta | Contenido |
|---|---|
| `index.html` | Sitio completo |
| `assets/` | Logos (SVG), fotos de producto y QR de Instagram |
| `archivo-pruebas-y-versiones/` | Versiones anteriores y pruebas |

Tipografías: Barlow Condensed e Inter (Google Fonts). No requiere build: se abre `index.html` directamente.
